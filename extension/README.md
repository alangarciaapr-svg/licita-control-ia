# Conector local LicitaControl IA

Versión beta del puente de navegador. No solicita, lee ni almacena credenciales, Clave Única o cookies. Solo confirma que la extensión está activa, detecta actividad reciente en un dominio de Mercado Público y recibe paquetes mínimos de trabajo por código.

## Instalación local

1. Descomprime `extension.zip`.
2. Abre `chrome://extensions`.
3. Activa **Modo de desarrollador**.
4. Selecciona **Cargar extensión sin empaquetar** y elige esta carpeta.
5. Abre LicitaControl IA y pulsa **Comprobar conexión**.

El llenado de formularios y el envío real no están habilitados en esta beta. Cada modalidad oficial requiere mapeo, pruebas y una confirmación humana antes de activar la transacción.
